{}
{
\item Built a full-stack developer portfolio with an MDX-based blog and a component-driven UI using Next.js, Tailwind CSS, and shadcn/ui.

}

\project
{Vaani}
{}
{https://github.com/nitishdeshmukh/vaani}
{}
{
\item Architected a distributed real-time chat application using Next.js, Express, Socket.io, and Redis Streams for low-latency message delivery.
\item Integrated Apache Kafka for asynchronous event processing and PostgreSQL with Prisma for reliable persistence of chat messages and application data.
}
